# Project Overview

GreenLeaf Market is a South African organic grocery brand offering fresh produce, dairy, smoothies and pantry items sourced from local farmers. This project involves building a fully functional, multi-page website that includes interactive JavaScript features, a gallery lightbox, enquiry and contact forms and SEO compliance.

# Website Goals & Objectives

Provide customers with clear information about products and the organisation

Improve user experience through interactive elements

Enable enquiries and communication through functional forms

Increase visibility using SEO best practices

Display images effectively using a product gallery with lightbox

Integrate dynamic JavaScript interactions

# Key Features

5-page website (Home, About, Products, Enquiry, Contact)

Responsive layout

Lightbox image gallery

Contact and enquiry forms with JavaScript validation

Leaflet interactive map with two South African locations

Clean navigation structure

On-page SEO (meta descriptions, headings, alt text)

robots.txt and sitemap.xml

# Sitemap
